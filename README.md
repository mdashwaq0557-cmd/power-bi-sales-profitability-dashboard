# Executive Sales & Profitability Analysis Dashboard

## Project Overview

This project presents an interactive three-page Power BI dashboard developed to analyze sales performance, profitability, regional trends, and product-level performance across a sales dataset covering 2015–2018.

## Objectives

- Monitor key business performance indicators.
- Analyze sales and profit trends over time.
- Compare regional and state-level performance.
- Evaluate category and sub-category sales.
- Identify profitable and loss-making product groups.
- Enable interactive analysis using filters and slicers.

## Dashboard Pages

### 1. Executive Sales Dashboard
Provides an overview of business performance through KPI cards, monthly sales trends, sales and profit by region, segment-wise sales, and sub-category sales.

### 2. Regional Performance Dashboard
Focuses on state-level geographical analysis, regional sales and profit comparisons, and a regional performance matrix.

### 3. Product Performance Analysis
Displays category-wise sales, product-level performance, profit margins, quantity sold, and profit by sub-category.

1. Download the Power BI report file from the `PowerBI` folder.

3. Refresh the data source if required and configure the correct file path.
4. Use the slicers and interactive visuals to explore the analysis.
